# Habla

A phone-first Spanish speaking trainer. Hear a phrase, say it out loud, get scored on how close you got — plus spaced-repetition review, roleplay conversations, build-a-sentence drills, a listening quiz, daily goals and XP.

Live speech scoring uses the browser's Web Speech API and works best in Chrome or on Android. All progress is saved locally in your browser.

**Play it:** https://jesgetme.github.io/habla/

Built as a single self-contained `index.html` — no build step, no dependencies beyond Google Fonts.
